# Khadidja Boutique

Boutique statique de robes pour femme, publiée avec GitHub Pages. Le catalogue, le panier et la préparation de commande se trouvent dans `store.js`. Le panier est conservé dans le navigateur du client.

Les deux robes sont affichées à 23 900 DA. La transmission des commandes est volontairement en attente : aucun canal de réception n'a été fourni. Le formulaire prépare un récapitulatif à copier et indique clairement qu'aucun message n'a été envoyé.
