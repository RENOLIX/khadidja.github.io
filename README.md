# Khadidja Boutique

Boutique statique de robes pour femme, publiée avec GitHub Pages. Le catalogue et la configuration de commande se trouvent dans `app.js`. Le panier est conservé dans le navigateur du client.

Avant d'accepter des commandes, renseigner le prix réel du produit et le numéro WhatsApp professionnel dans `app.js` (`CONFIG.priceDa` et `CONFIG.whatsappNumber`). Tant que ces valeurs sont absentes, l'interface indique clairement que le prix est à confirmer et ne prétend pas transmettre une commande.
