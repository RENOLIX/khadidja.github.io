# Khadidja Boutique

Boutique statique de robes pour femme, publiée avec GitHub Pages. Le catalogue et la configuration de commande se trouvent dans `app.js`. Le panier est conservé dans le navigateur du client.

Le prix de la robe est renseigné dans `app.js` (`CONFIG.priceDa`). La transmission des commandes est volontairement en attente : aucun numéro WhatsApp n'a été fourni. Le formulaire prépare un récapitulatif à copier et indique clairement qu'aucun message n'a été envoyé. Pour activer l'envoi WhatsApp ultérieurement, renseigner `CONFIG.whatsappNumber` au format international sans `+`.
